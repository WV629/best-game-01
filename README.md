Shardstorm is a neon arena survival shooter: pilot a lone ship through escalating waves of shard-creatures, dash through danger, collect the shards they drop, and pick one of three upgrades after every cleared wave — including a boss, the Shardlord, every fifth wave. WASD or arrow keys to move, mouse to aim, hold click to fire, Space to dash. Five enemy kinds (drifter, dart, splitter, spitter, boss), combo scoring, particles and screen shake, synthesised WebAudio sound and music, a title screen, wave-clear upgrade cards, pause, and a game-over screen with a persistent best score. Pure static files — HTML plus ES modules, no libraries, no network requests — playable offline in any desktop browser.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080. Or open `game/index.html` directly in a browser.
